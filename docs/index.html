Architecture Blueprint

Structured Operations Architecture

Seven robust functional modules designed strictly according to the System Requirements Specification.

Authentication & Audit Trail

TOTP Two-Factor Authentication (2FA) for administrators, 30-minute idle session timeout, and immutable audit logs capturing actor, IP address, and model mutations.

Module 01 • RBAC & Security

Employee Master Vault (PIM)

Lifecycle management with sequential employee code generation (EMP-YYYY-XXXX), AES-256 encrypted documents, and interactive departmental org tree.

Module 02 • Master Records

Geofenced Attendance

Single-click digital punch-in validated via HTML5 GPS perimeter checks (100m radius), rotational shifts, grace periods, and configurable overtime multiplier engines.

Module 03 • Time Tracking

Leave & Absence Governance

Automated pro-rated entitlement accrual, dual-step approval chain (Manager → HR), instant overlap prevention checks, and team absence calendar sync.

Module 04 • Multi-Tier Approvals

Performance Appraisals & OKRs

Quarterly quantifiable Objectives and Key Results with live progress bars, 360-degree review forms (Self, Peer, and Manager evaluation) with weighted scoring.

Module 05 • Appraisal Matrix

Recruitment & ATS Pipeline

Public career openings portal, drag-and-drop applicant Kanban stages, formatted employment offer letter generator, and single-click employee onboarding.

Module 06 • Talent Acquisition
Module 07 • System Integration Decoupled Architecture

Dedicated Payroll Synchronization Hub

To ensure modular software segregation, payroll calculation and statutory tax deductions are decoupled from HRMS. PulseHR exports synchronized employee master records, verified work hours, and unpaid leaves to PayFlow MY via authenticated REST endpoints and scheduled CSV feeds.

Engineering Foundation

Technical Specifications

Modern enterprise stack crafted for high-concurrency workloads and strict security compliance.

Laravel 12.x Backend

PHP 8.3 with strict type declarations, Eloquent ORM eager-loading to eliminate N+1 queries, and automated Pest PHP test suites.

Tailwind CSS & Vite

Modern Tailwind color design tokens, fluid dark/light theming, Boxicons, Animate.css, and instantaneous hot-module replacement.

PostgreSQL & Redis

ACID relational compliance, Redis queue workers for asynchronous export jobs and transactional notification dispatchers.

Enterprise Security

PII encryption at rest via Laravel Crypt facade, Spatie RBAC guards, CSRF token validation, and rate-limiting controllers.
